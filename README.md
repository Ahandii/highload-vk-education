# Расчетно-пояснительная записка для Курсовой работы
**по предмету:** «Проектирование высоконагруженных систем»

## 1. Тема и целевая аудитория

**Тип:** B2B/B2C логистический сервис (система трекинга и управления отправлением).  
**Аналог:** СДЭК.

**Целевая аудитория:**  
~2 млн MAU мобильного приложения. Десятки миллионов пользователей веб-версии (переходы по ссылкам из интернет-магазинов). Сервис «СДЭК Shopping» входит в Топ-3 сервисов доставки товаров из-за рубежа по месячной аудитории (MAU). Продукт ориентирован на рынок России и стран СНГ.

**Основной функционал MVP:**
1. Прием и валидация событий от терминалов сбора данных (ТСД), складских сканеров и приложений курьеров в реальном времени.
2. Публичный трекинг посылки по трек-номеру (мгновенный поиск и выдача истории перемещений).
3. B2B API для интернет-магазинов (расчет стоимости, создание накладной, получение вебхуков при смене статуса).
4. Управление географией, графиком работы и заполненностью ячеек постаматов и пунктов выдачи заказов (ПВЗ).
5. Система триггерных уведомлений (Push/SMS) при критических сменах статуса (например, «Прибыло в город» или «Готово к выдаче»).

**Ключевые продуктовые и архитектурные решения:**
* **Асинхронная обработка (Event-driven):** Поток событий от сканеров (более 58 000 посылок в минуту) принимается через брокер сообщений (Kafka). Это гарантирует, что ни один статус не потеряется даже при резких пиках нагрузки (например, перед праздниками).
* **Разделение чтения и записи (CQRS):** Запись новых событий идет в защищенный лог, а клиент читает уже денормализованные и закэшированные данные. Это обеспечивает мгновенный ответ на запрос «Где моя посылка» без нагрузки на основную базу данных.
* **Приоритизация трафика:** Критические B2B-вебхуки и финальные статусы («Вручено») обрабатываются вне общих очередей с высшим приоритетом.

**Список источников:**
1. Официальный пресс-релиз СДЭК: «СДЭК в первом полугодии нарастил объем отправлений на 14%» (56,5 млн посылок за H1 2024). Август 2024.
2. Официальный пресс-релиз СДЭК: «СДЭК 25 лет» (статистика: обработка более 58 000 посылок в минуту, рост доставок на 54% за 5 лет). Февраль 2025.
3. Аналитика Tele2 / CNews: «Интерес россиян к сервисам доставки товаров» (СДЭК Shopping в Топ-3 по MAU). Январь 2024.
